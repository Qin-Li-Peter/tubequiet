TubeQuiet reduces supported advertising on YouTube. It does not collect or transmit personal information to its developer, does not use analytics, and does not operate a filtering server.

## Local processing

TubeQuiet reads and modifies recognized YouTube player advertising data in memory and hides supported ad elements. Page data is not stored as browsing history, sent to the developer, or sold. The extension stores only an enabled/paused preference in Chrome's local extension storage. It does not use Chrome Sync.

The popup checks whether the current tab is on a supported YouTube host to offer a reload button; it does not retain or transmit that URL. Normal requests made by YouTube remain subject to YouTube's own policies. Chrome Web Store distribution and updates are handled by Google.

## Permissions

YouTube host access and scripting enable local player-data and page filtering. declarativeNetRequest enables packaged advertising-request rules scoped to YouTube initiators. storage retains the local preference.

## Your choices

Pause protection from the popup and reload every open YouTube tab to fully apply the change. Uninstalling the extension removes its local extension storage. No developer-held user database exists to request deletion from.

## Limited use and changes

Any use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. TubeQuiet does not use Google account APIs. If future versions change data handling, this policy and the store disclosures will be updated before release.

For questions, contact the publisher at the address above. TubeQuiet is not affiliated with Google or YouTube.
